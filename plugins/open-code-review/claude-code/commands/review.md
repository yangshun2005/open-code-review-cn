调用专业的代码审查 Agent CLI 工具 OpenCodeReview (OCR) 来审查当前的代码变更，并让 Agent 自主决定是否应用修复。

## 工作流程

### 步骤 1：运行代码审查

运行 OCR 命令：

```bash
ocr review --audience agent [用户参数]
```
- 默认（无用户参数）：审查已暂存、未暂存和未跟踪的变更（工作区模式）。
- 如果用户提供 `--commit` 或 `--c`：按原样传递。
- 如果用户提供 `--from` 和 `--to`：按原样传递。
- （可选）提供 `--background "需求上下文"` 以审查需求是否正确实现。
- （可选）提供 `--background-file ./requirements.md` 从 Markdown 文件加载相同上下文（经过清理并限制为 8000 个字符）。与 `--background` 结合使用时，内联值优先。
- 捕获完整的标准输出。设置 5 分钟超时。
- 如果找不到 `ocr` 命令，通过运行 `npm i -g @alibaba-group/open-code-review` 进行安装。

### 步骤 2：筛选与评估

对每条评论，评估其有效性和质量：

- **高**：明显的错误、安全问题、清晰失误，或带有精确修复建议的合理建议
- **中**：合理的关注点但依赖上下文，风格/性能建议，或需要手动实现的修复
- **低**：可能是误报、缺乏足够上下文、吹毛求疵或无意义的建议

静默丢弃低置信度的评论。显示其余评论。

### 步骤 3：修复

自动修复值得采纳的问题和建议。
