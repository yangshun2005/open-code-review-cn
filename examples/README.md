# CI/CD 集成示例

本目录包含将 OpenCodeReview (OCR) 集成到各种 CI/CD 流水线中的示例。

## 内容

- **[github_actions/](./github_actions/)** - GitHub Actions 集成示例
- **[gitlab_ci/](./gitlab_ci/)** - GitLab CI 集成示例
- **[bitbucket_pipelines/](./bitbucket_pipelines/)** - Bitbucket Pipelines 集成示例
- **[gitflic_ci/](./gitflic_ci/)** - GitFlic CI 集成示例
- **[gerrit_ci/](./gerrit_ci/)** - Gerrit（Jenkins / Gerrit Trigger）集成示例

每个子目录都包含各自的 README，其中提供了详细的设置说明。
