### 任务

以下是一个或多个相关文件的 diff，以及一组针对它们的审查评论。只找出这些 diff **证明**为错误的评论。

每条评论都带有一个 `path`。路径相同的 `<file>` 元素就是该评论的对象；其他文件是上下文。它们可以为跨文件评论提供依据，但绝不能替代对象文件——组中某处存在的代码，并不等于评论所针对的文件中存在该代码。

你的默认答案是全部批准。在大多数审查中，这就是正确答案。

### 仅有的两种移除理由

**理由 A——评论针对的代码不在其对象文件的 diff 中。**

评论所描述的函数体、语句或结构，在评论所指路径的 `<file>` 中完全不存在。此理由仅针对该文件判断——同一结构出现在同级文件中不能挽救该评论。典型情形：

- 它讨论某个函数的函数体，而该文件只声明或引用了该函数
- 它讨论宿主语言逻辑，而该文件不含任何此类逻辑——查询、构建、标记或配置文件
- 它声称代码被删除，或错误已被处理，而其对象文件的 diff 中并无此类改动

**理由 B——某条具体 diff 行直接与评论的核心主张相矛盾。**

评论断言某个具体事实，而 diff 以明文显示相反情况。与理由 A 不同，矛盾行可以位于组中任意 `<file>`：一条称某标识符未使用的评论，只要这些文件中任意一个使用了它，就是错的。矛盾必须能从 diff 直接读出，不能通过推理链推导。典型情形：

- 它说某标识符未使用，而 diff 显示它被使用
- 它说缺少某项检查、断言或分支，而 diff 中包含它
- 它说某值是硬编码的，而 diff 显示它从变量读取
- 它说某物被声明两次并遮蔽了外层名称，而 diff 中恰好只有一处声明
- 它陈述的条件或类型关系被 diff 自身文本否定

如果你无法指出确立理由 A 或理由 B 的具体 diff 行，就批准该评论。

### 受保护主题——绝不移除

这些是否决项，在你判断正确性之前就适用。无论你对评论的结论如何，只要其主题是以下之一，就批准：

- **内存安全**——分配大小、缓冲区长度、索引边界、差一错误、释放后使用、空指针解引用
- **并发**——锁与锁模式、原子操作、数据竞争、未被遵守的同步论证
- **链接与声明一致性**——`static` 与非 `static`、声明与定义不一致、缺少 `extern`
- **行为或兼容性变更**——旧代码产生而新代码不再产生的消息、字段、状态或默认值；被改变的 error 路径；更新时机被移到生命周期中另一位置的计数器
- **函数接受但从未使用的参数**

这些类别中，错误移除评论的代价最高，而你自己的信心最不可靠——包括对语言、编译器或运行时不会如评论所称那样行为的信心。在受保护主题上，你无权自信。批准。

### 不作为移除理由

- 评论涉及风格、格式、命名、空行、代码注释措辞或可读性——**只要其陈述为真**。价值低不等于不正确，按价值过滤不是你的职责。
- 评论对运行时行为、业务语义或你看不到的文件中的代码进行推理。Agent 拥有你没有的访问权限。
- 你不同意其建议，或你认为被标记的代码按原样可接受。
- 你无法确认。无法验证不等于不正确。
- 它指出了真实问题，但引用了略有错误的行或片段。判断主张，而非引用。
- 它顺带不精确，但核心主张成立。

### 方法

对每条评论按顺序执行以下步骤。在第一个适用步骤停止——不要重新审视后续步骤可能做出不同决定的决策。

**步骤 1——受保护主题否决。** 评论的主题是否属于上述受保护类别（内存安全、并发、链接与声明一致性、行为或兼容性变更、未使用参数）？→ **批准并停止。** 不要评估其是否正确。此否决优先于理由 A 和理由 B：受保护主题的评论即使你确信其错误也保留。

**步骤 2——价值否决。** 评论是否涉及风格、格式、命名、空行、代码注释措辞或可读性，且其陈述对此 diff 为真？→ **批准并停止。** 其低价值不是你的关注点。

**步骤 3——理由 A。** 它描述的代码是否不在其对象文件的 diff 中？→ **移除它。**

**步骤 4——理由 B。** 组中任意文件中是否存在一行 diff，字面上与其核心主张矛盾，无需推理链即可看出？→ **移除它。** 步骤 3 和 4 不是可选的：一旦评论到达这些步骤并符合条件，就报告它。

在步骤 4 得出矛盾结论之前，在每个 `<file>` 中搜索评论所描述的内容——不仅是它引用的片段。一条引用了错误行但描述了 diff 中确实存在内容的评论是正确的，应保留。

**步骤 5——** 批准。

到达步骤 4 且需要超过一个推理步骤才能得出矛盾，意味着不存在矛盾。批准。

- `report_incorrect_comments`——仅用于符合理由 A 或理由 B 的评论，且仅当你能为每条评论指出证伪它的 diff 行。
