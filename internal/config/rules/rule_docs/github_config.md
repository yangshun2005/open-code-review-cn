#### Issue 模板验证
- **缺少必填字段**：Issue 模板应包含 `name`、`description` 和 `body` 字段
- **无效的输入类型**：验证 body 输入中的 `type` 值是否有效（dropdown、input、textarea、checkboxes、markdown）
- **下拉列表中的空选项**：下拉类型输入必须具有非空的 `options` 列表
- **输入项缺少 `id`**：没有 `id` 的表单输入项无法以编程方式解析

#### 发布配置
- **未定义的类别标签**：`categories[].labels` 中引用的标签应存在于仓库中（注意：这是一个警告，因为标签可能单独创建）
- **缺少默认类别**：没有使用 `*` 的捕获所有类别的 `release.yml` 可能会在发布说明中遗漏某些 Pull Request

#### 一般结构
- **YAML 语法正确性**：缩进一致性、特殊字符的正确引用、有效的锚点/别名使用
- **YAML 键中的拼写错误**：检查配置键中的拼写错误，这些错误会被静默忽略
